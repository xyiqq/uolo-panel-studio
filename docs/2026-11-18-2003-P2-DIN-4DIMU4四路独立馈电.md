## 需求与变更

- 实现 DIN-4DIMU4（6513187）四路各自的 L/N 馈电，保持 24V 控制供电独立，核对画面、实际 PDF 和 CSV。
- 简易和完整模式均可逐路选择不同的 220V 单相支路。各路从自己的保护路径进入 L、N 端子，DIM 相线和同通道 N 通往对应出箱端子。带漏保的回路从该路漏保的 N 出口取零线。模块上端绘制四组 N/L/D，下端显示 NET 24/G。
