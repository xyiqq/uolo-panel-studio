# 2026-09-18 装配视口上下栏可显隐

## 日期
2026-09-18

## 目标与用户授权范围
用户反馈中间配电箱模型偏小，被视口上下栏挡住；要求顶部机柜信息与底部组件/相电流条可独立隐藏与显示。

## 环境
- Windows / Vite preview `http://127.0.0.1:4175/`
- Playwright 探测

## 操作与证据
1. 左侧工具栏新增「panel-top / panel-bottom」按钮：`#chrome-top`、`#chrome-bottom`。
2. CSS：`.chrome-hide-top` 隐藏 `.canvas-top`；`.chrome-hide-bottom` 隐藏 `.parts-dock`、`.phase-strip`、`.view-bottom`、`.wire-legend`。
3. 切换后调用 `resize()` + `fit()`，取景按 Studio3D `viewport()` 实际占位重算；状态写入 `localStorage`（`panel-studio-chrome`）。
4. `probe-chrome.mjs`：隐藏后 `display:none`，相机 z 3550→3279（更近）；截图 `docs/_smoke-chrome-hidden.png`。
5. `npm test` 22 通过。

## 实际改动文件
- `src/ui/app.js`：工具按钮与显隐逻辑
- `src/styles/app.css`：显隐样式
- `docs/_smoke-chrome-hidden.png`、本记录
- `scripts/probe-chrome.mjs`（验证脚本）

## 验证结果
- 按钮存在；点击后 class `chrome-hide-top/bottom` 生效
- 顶部标题条与底部组件条消失；视角控件仍保留
- 单元测试通过

## 风险与未验证项
- 未改左右侧栏；极窄高柜在透视下两侧仍会有留白
- 用户本机需硬刷新加载新 `dist`

## 回滚方式
还原 `app.js` / `app.css` 本轮改动并重建；清除 `localStorage.panel-studio-chrome`。

## 下一步
若仍觉得小，可再做「隐藏左右侧栏」或正视默认取景。
