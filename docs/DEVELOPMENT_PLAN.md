# 配电工坊后续开发计划

更新：2026-09-21。以当前代码为依据，承接《2026-09-18-配电工坊V5整体实施计划》。旧阶段日志保留历史，不再作为全部验收完成的依据。

## 本次已完成：配线 → 系统图 → 接线表 → BOM

- 完整模式按保存的模块通道/器件链生成共享或逐通道馈电、控制器和电表串接，采用真实上游保护参数；简单模式保留空开与模块一对一对应。
- 根据明确关联的单电源和匹配端口生成 24V DC、KNX、DALI 连接；未知截面及无法确定的电气关系给出待核，DC/通信不套用交流电力 Iz 校核。
- 系统图、箱门表展示共享模块、实际馈线、通道、端子、电表和总线预算，链路明细自动分页。
- 保存的端子接线进入统一交付网络，与接线表、CSV、号码管、BOM 同步；手填线号保留。通道串接电表时，实物端子接到电表输出，不绕过电表或再重复生成虚拟 X 相线。
- 箱内导线按端点距离及余量估算，出箱电缆按各回路每芯长度单独计一次；箱内截面覆盖不改变出箱截面。简单模式也开放系统图、接线表和号码管。
- 交底 ZIP 包含独立 HTML、方案、端子接线 CSV、BOM、系统图等资料；无效关联在文档中可见，不静默伪造连接。
- 同批收录已验证的安装记忆、模块ID行内提示、端子顺序连接/线号/线径、产品参数修正、紧邻模型、完整链路拆解与负载零线显示。拆解固定100%。

### 本次明确保留的边界

- 端子交付网络是保存接线的投影，不把手工灯具连接当作已完成负载导通/电机互锁仿真。
- 多电源自动并联、多个独立保护回路共接未核实的模块零线、多级控制器、三相模块链不猜接，列为待核。
- Cresnet/RS485/0–10V 等端子与专用线缆未完全确认时不自动生成；不是已经完成的协议仿真功能。
- BOM 为备料估算，不是实测长度。未填出箱长度的回路不编造米数，未知截面保留待核。

## 下一阶段一：电气校核与分排

| 项目 | 待做 | 验收标准 |
|---|---|---|
| 模块额定与保护配合 | 通道额定、模块总额定、保护器上游额定、缺零检查 | 每规则具正反例，提示能定位到模块及回路 |
| 电源与总线 | DC功率预算、SELV隔离、电子模块漏保提示、金属箱无线提醒 | 预算单位一致，未知参数不得当零消耗 |
| 已保存链路进一步扩展 | 多级控制器、三相、厂商特定共零/逐路端口、Cresnet/RS485/0–10V | 先补有出处端口资料，再做网络/图纸/清单一致性测试 |
| 总线编辑界面 | 电源、成员、类型、电压、线径、线缆规格和长度可编辑 | 保存刷新不丢，待核原因可在界面直接修正 |
| 强弱电排分区 | 每排power/control设置与自动排布约束 | 重新排布不混排，手动冲突明确提示 |
| 空间审计 | 高度/深度/散热待核规则 | 与箱体推荐使用同一参数，粗估标明依据 |

## 下一阶段二：方案管理与交付流程

| 项目 | 待做 | 验收标准 |
|---|---|---|
| Schema v3 | 主应用导入、保存与导出真正接入迁移入口 | V2迁入、V3重载、旧方案可回退，已有模块数据无损 |
| 多方案管理 | 接通StorageAdapter，列表/新建/复制/切换/删除 | 重启仍可找回多方案；旧本地key保留 |
| 在线方案链接 | 解析 /d/:id 与 ?c= 定位 | 存在方案可打开，不存在明确提示导入 |
| 标签纸 | A4 30格、48格、自定义行列/边距 | 打印实测尺寸，不截断文字 |
| 修订签认 | 导出前修订摘要、日期/备注编辑 | Rev与图纸、封面、ZIP一致 |
| 部署验收 | Docker运行、离线HTML、扫码与打印矩阵 | Docker /d 不404；Chrome/Edge PDF、手机扫码有证据 |

## 下一阶段三：产品与可维护性

- 自定义产品编辑器补通道额定、总线消耗、PSU输出、发热、厂家端子等字段。
