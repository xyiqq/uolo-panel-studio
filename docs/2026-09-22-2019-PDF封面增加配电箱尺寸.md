# PDF 封面增加配电箱尺寸

用户要求在配电箱导出 PDF 的第一页标注箱体尺寸。

- 修改 `src/view/documents/cover.js`，在箱体名称旁增加尺寸，明确顺序为宽 × 高 × 深，单位 mm。
- 优先使用当前箱体 `outer` 外形尺寸；无完整外形尺寸时使用箱体 width、height、depth。估算箱体明确注明待实物确认，缺失尺寸显示“待填写”。
- 已检查默认 MH-144 外形尺寸 520 × 1205 × 176.5 mm、自定义尺寸回退和缺失值；构建通过。
- Chrome 实际导出并渲染第一页检查，尺寸显示完整，未出现重叠或越页。样张：`output/pdf/配电箱尺寸-封面样张.pdf`。
- 未提交或部署；尺寸来自当前方案箱体资料，未进行实物测量。
