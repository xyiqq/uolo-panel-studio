# 2026-09-18 全模块精绘与自定义 DIN 模板

## 日期
2026-09-18

## 目标与用户授权范围
用户确认智能面板精绘可用后，要求：
1. 其余模块（断路器 / 漏保 / SPD 等）也改为精绘面板；
2. 加入快思聪 Crestron **DIN-DLI**；
3. 自定义模块提供若干精绘 DIN 尺寸模板，填写品牌与型号后自动生成新模块。

## 环境
本地项目 `uolo-配电箱`（V5 / Vite / Vitest）

## 操作与证据
- 新增 `src/view/breaker-face3d.js`：按贴图宽高比生成高分辨率断路器正面纹理（约 20 px/mm）。
- `src/view/studio3d.js` 的 `Xo` 改用 `makeBreakerFaceTexture`；端子标签改为更高分辨率；补上 `productPoleKeys` 导入。
- `src/data/products/smart-crestron.js` 增加 `crestron-din-dli`：3M，52.83×93.7×59 mm（Spec Sheet）。
- 新增 `src/data/products/custom-templates.js`：1/2/3/4/6/9/12M 精绘尺寸芯片。
- `validateCustomProduct` 扩展智能 kind（gateway/relay/dimmer/psu/meter/contactor/timer），自动 `modules/smart/zone/protocol`。
- `validateDesign` 允许智能模块作为回路 `productId`。
- `qX` 自定义表单：尺寸模板芯片 + 品牌/型号自动生成名称预览 + 保存入库。

## 风险与未验证项
- 自定义智能模块装入后仍可能触发漏保/电缆等审计 pending/error（占位演示可用，不视为施工结论）。
- 断路器面板为参数化精绘，非厂家官方矢量商标；仅用于机柜布局预览。
- DIN-DLI 电气额定仍为待核，仅外形按 Spec Sheet。

## 回滚方式
还原上述文件；删除两个新增文件即可回到精绘前断路器贴图与无 DIN-DLI/自定义模板状态。

## 下一步
浏览器打开产品库 →「新增品牌 / 型号」→ 点选 DIN 模板 → 填品牌型号保存 → 装入设备，确认三维精绘面板；搜索 DIN-DLI 装入核对 3M 占位。
