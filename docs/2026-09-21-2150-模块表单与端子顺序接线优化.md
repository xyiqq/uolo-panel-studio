# 模块表单与端子顺序接线优化

时间：2026-09-21，Asia/Shanghai。

## 用户需求与实际修改

- 模块 ID 非法或重复时，在模块弹窗输入框下显示错误，保存时聚焦该字段；其它保存错误显示在表单内。
- 安装位置在本地按智能模块、端子、保护器件分别记忆；刷新保留。原位置占用时优先同排后续空位，再同排其它空位、后续排或首个空位。编辑已有设备仍使用设备自己的位置。
- PT2.5 自动排布从第一排可用槽位开始，不再跟随继电器或接线关联；保留固定位置与连续端子的实际宽度贴合。
- 首节选择输出后，就地提示按顺序连接后续空白端子。按模块与通道顺序填充当前端子组，保留已有接线、跳过占用通道；通道用完停止，仍需点击保存接线。
