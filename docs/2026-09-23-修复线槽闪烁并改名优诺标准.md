# 修复线槽闪烁并改名优诺标准

- 日期：2026-09-23。
- 目标与授权：用户反馈三维视图中线槽闪烁（附截图：左侧竖槽外侧出现斜纹闪烁），并要求把“按 UOLO 标准”改为“优诺标准”。未提交、未部署。
- 环境：Windows PowerShell；项目 `C:\Users\zhang\Projects\uolo-panel-studio`；Vite 服务 http://127.0.0.1:5174/ 热更新。

## 原因

- 深度冲突（z-fighting）：竖槽最外侧槽壁的中心是 `±(内部宽/2 − 1.5)`、厚 3 mm，与箱体侧板（同样位于 `±(内部宽/2 − 1.5)`、厚 3 mm）完全重合；顶部、底部横槽的外壁与箱体顶板、底板也重合；线槽底板（z 0–3）还与安装背板（z 2.25–3.75）重叠。重合的面深度相同，渲染时交替显示，于是出现闪烁。

## 实际改动

| 文件 | 改动 |
|---|---|
| `src/view/wire-ducts3d.js` | 新增 `renderRect`：竖槽外侧与上下两端让出箱体壳体厚度 3 mm 再加 0.5 mm 间隙；顶、底横槽外侧同样让出；横槽两端各留 0.5 mm；槽底从安装背板前表面 z=3.75 再往前 0.2 mm 开始，槽壁与槽底之间留 0.5 mm。线槽的逻辑布局（`wireDuctRects`）不变，只调整渲染几何。 |
| `src/ui/app.js` | 下拉分组“UOLO 线槽箱”改为“优诺线槽箱”（按品牌“优诺”筛选）；按钮文字改为“按优诺线槽标准…”。 |
| `src/ui/duct-cabinet-dialog.js` | 对话框标题改为“优诺线槽标准箱体”，说明文字改为“按优诺主图标准生成”，生成的箱体名称为“优诺标准 …”。 |
| `src/data/cabinets/uolo.js` | 品牌改为“优诺”，型号名改为“优诺线槽箱 · …”，来源说明改为“优诺线槽箱标准：…”。型号 ID `UOLO-63x…` 保持不变，已保存的方案不受影响。 |
| `src/view/studio3d.js` | 三维铭牌改为“优诺 / 宽x高”。 |
| `tests/core/uolo-cabinets.test.js` | 新增：6 个型号的全部线槽面与箱体侧板、顶底板、安装背板之间都有间隙，线槽之间也不相交、不共面。 |
