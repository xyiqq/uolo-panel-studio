# DIN-8SW8 负载零线与固定拆解

## 需求
DIN-8SW8 的零线在正常与拆解视图中显示；删除展开程度控制，拆解固定 100%。

## 完成修改
- 保留继电器负载侧原有 X 回路零线的真实起终点、线号、断线和仿真状态，增加模块关联标记。
- 正常、单模块及空开链路拆解中均显示蓝色负载零线和“负载零线（直达负载）”标签；就近负载参考点随模块位移，远处零线排可用局部引入点表示。
- 核对厂家安装图，零线直接通负载，控制侧由 Cresnet 供电。移除原通用端口生成器为此型号虚构的 N_IN，未将零线接入不存在的模块端子。
- 删除展开程度滑块、数值控件、事件与状态变量，UI 始终传入 explodeAmount=1；保留拆解开关和过渡动画。

## 关键文件
`src/core/module-feeds.js`、`src/core/ports.js`、`src/core/domain.js`、`src/view/exploded-wiring.js`、`src/view/terminal-studio3d.js`、`src/ui/app.js` 及相关测试。
