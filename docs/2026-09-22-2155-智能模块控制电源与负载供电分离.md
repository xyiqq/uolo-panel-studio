# 智能模块控制电源与负载供电分离

- 时间：2026-09-22 21:55（Asia/Shanghai）
- 项目：uolo-panel-studio

## 用户需求
截图中的继电器、调光器与 DIN-DLI 在 24V 电源输出选择器被误判不匹配。要求根据厂家官网核实模块供电，并区分模块控制电源与灯具／设备的负载供电。

## 实际修改
- 官网核查及逐型号来源见《2026-09-22-Crestron控制侧与负载侧供电核查.md》。已核实的 Crestron 模块控制侧改为明确的 24VDC 或 24VDC/PoE；保留调光器市电供电及 0.6W 的条件说明。
- 产品新增 loadPowerInput 记录负载侧市电输入；端子、馈电、零线审计与接线分别采用控制侧/负载侧参数。旧产品没有新字段时沿用原字段，历史未核实型号不猜测参数。
- 继电器和调光器新增独立 DC+/DC− 输入，24V PSU 多选关联生成控制供电线；支路空开至负载侧的线路保持独立。DC负极不作为市电零线。
- 编辑窗和属性栏说明“模块本身供电”与“灯具／设备负载供电”；负载空开选择改名，纯低压网关不再显示市电空开入口。
- DIN-DLI 官方禁止外接 DALI 电源，选择器禁止新增该接法；旧关联保留待核、不画并联线。DIN-DALI-2 需确认 EXT 外置模式，本次不猜测开关状态。
- 接线用途和 PDF 接线表区分直流控制供电、负载供电与负载零线。
