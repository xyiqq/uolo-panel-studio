# PDF 加入三维图与现场实拍

用户要求交付 PDF 包含三维配电箱图和装配完成后的图片；经确认，第二张采用用户上传的现场实拍照片。

## 实际修改

- 在项目配置 → 项目信息与设计条件中增加现场照片上传、预览、更换、移除。点击应用才保存，取消不修改原照片。
- 支持 JPG、PNG、WebP，上传上限 12 MB；浏览器解码后等比压缩为最长边 1600 像素的 JPEG，控制本机方案存储体积。照片随方案 JSON 与离线 HTML 保存，不上传服务器。
- PDF 封面后加入“三维配电箱方案图”；上传照片后再加入“配电箱现场实拍”。无实拍照片时不创建空照片页。简易、完整模式均支持选择这两页。
- 三维图片独立以 1200 × 1500 像素渲染，显示完整箱体及当前布置、隐藏箱门与选择框；导出后恢复原相机、隔离和爆炸视图状态。图片用于方案参考，不替代现场照片。
- 图像页固定版心，等比例完整显示，不变形或裁切。打印前等待图片解码，失败时给出提示，避免静默打印空白图片。
- 修复仅保存项目信息／照片也触发接线重置的问题；电气或布局条件未改变时保留断线状态与导线规格编辑。
