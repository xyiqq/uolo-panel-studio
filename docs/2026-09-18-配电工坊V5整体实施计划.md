## 3. 目标、范围与黄金基线

### 3.1 目标

1. 把 V4 恢复为可维护的源码工程，并复现 V4 全部功能。
2. 支持**多品牌混用**的智能模块（Crestron、Lutron、KNX、涂鸦 DIN、明纬 DIN 电源、DALI 电源，以及用户自定义），含总线预算。
3. **空间计算**：放入器件后自动得出需要的模位数（M）、排数、箱体最小尺寸，并从扩展的箱体库（含通用规格）推荐箱体。
4. **文档中心**：系统图、回路表、箱门总表、标签（面标/号码管/挂牌/铭牌）、接线表、BOM、检查单，统一预览、A4/A3 打印为 PDF、SVG 下载，含二维码。
5. 施工包：BOM/线材估算、检查与验收单、修订与签认、ZIP 打包。
6. Docker 部署预留与实现（静态托管）。

### 3.2 范围外

HA 联动、报价系统、多用户、云端存储、直连打印机（只留接口）。

```ts
interface DesignV3 {

  signoff: { designer?: Sign; reviewer?: Sign; installer?: Sign };   // Sign = { name, at, note }

  customCabinets: Cabinet[];
  spareRatio: number;             // 备用模位比例，默认 0.25

  loads: Load[];                  // 不变
  circuits: CircuitV3[];
  modules: SharedModule[];        // 多路模块实例（继电器/调光/电表/网关/电源等，跨回路共享）
```

### 5.2 回路

```ts
interface CircuitV3 {
  id; name; group; path; loadIds; voltage; phase; pf; method; ambient; bunched; length; wire; on; position;
  devices: DeviceRef[];           // 有序器件链，替代 productId/rcdProductId
  loadTags?: string;              // 标签用途文案覆盖
}
type DeviceRef =
  | { role:"protection"; productId: string|null }           // null=自动选型（保持 matchCircuit）
  | { role:"rcd"; productId: string }
  | { role:"control"; moduleId: string; channel: number }   // relay/dimmer/contactor/timer
  | { role:"meter"; moduleId: string; channel?: number };
```

迁移：`productId → devices[{protection}]`，`rcdProductId → devices[{rcd}]`。

### 5.5 箱体

```ts
interface Cabinet {
  id; name; brand: string;            // "玛德克" | "通用" | 用户
  mount: "明装"|"暗装";
  rows: number; slots: number; slotWidth: 18;      // 保持 18 兼容 3D
  width; height; depth;               // 内部安装空间 mm
  outer: [w,h,d];                     // 外形 mm
  pitch: number; topRail: number;     // 排距/首排上沿
  rowClearance: number;               // 排内允许器件最大高度（默认 pitch-45）
  maxDeviceDepth: number;             // 允许器件最大深度（默认 depth-25）
  zonesDefault: ("power"|"control")[];// 每排默认分区，默认全 power、最后一排 control
  source: string; estimated: boolean; // estimated=true 表示通用估算尺寸
  priceReference?: number|null;
}
```

**通用规格生成器**：`makeGenericCabinet(rows, slots, depth, mount)`：
`width = slots*18 + 70`，`height = 150 + rows*150 + 100`，`pitch = 150`，`topRail = 150`，`outer = [width+30, height+30, depth+18]`，`estimated:true`，`source:"通用估算尺寸，须以所选厂家图纸为准"`。
预置：1×12、1×16、1×18、1×20、1×24、2×12、2×18、2×24、3×24、4×24、5×24、6×24，深度 90/120/150 三档。用户可编辑保存为 `customCabinets`。

### 5.6 端子模板

```ts
interface PortTemplate { key: string; conductor: "L"|"N"|"PE"|"AUX"|"BUS+"|"BUS-"|"A"|"B"|"DC+"|"DC-"|"S"|"OUT"; side:"top"|"bottom"; io:"in"|"out"|"both"; channel?: number; minWire?; maxWire? }
```

- 保护器/隔离开关：由 `poles/neutralSide` 自动生成（沿用 `productPoleKeys` 逻辑），无需手写。
- 继电器/调光/接触器：`L_IN,N_IN`（取电）+ 每通道 `CHn_IN/CHn_OUT`（perChannel）或 `CHn_OUT`（shared）+ 总线端子。
- 电表 direct：`L_IN/L_OUT/N_IN/N_OUT`（×相数）+ `A/B`；ct：`L1..L3,N`（采样）+ `S1/S2`（×相数）+ `A/B`。
- PSU：`L_IN,N_IN` + `DC+/DC-` 或 `BUS+/BUS-`。
- 网关：按 `powerInput` 生成取电端子 + 总线端子。

### 5.7 标签规则

```ts
interface LabelRules {

  faceTemplate: string;       // 默认 "{id} {name} {in}A"
  wireTemplate: string;       // 默认 "{circuit}-{conductor}"
  terminalPrefix: { N:"XN"; PE:"XPE"; load:"X" };
  qrMode: "offline"|"online";

```

### 5.8 迁移 `migrateV2ToV3(v2): DesignV3`

1. 通过 `validateDesignV2`。
2. 生成 `designId/createdAt/updatedAt/revisions:[{summary:"由 V4 方案迁移"}]/signoff:{}`。
3. 回路 `productId/rcdProductId → devices`。
4. `modules:[]`，`buses:[]`，`customCabinets:[]`，`spareRatio:0.25`，`labelRules` 默认，`publicBaseUrl:null`。
5. 产品补 `zone:"power"`、`ports` 由旧规则生成。
6. 通过 `validateDesignV3`。

`loadDesign(raw)`：`raw.version===3 → validateV3`；`===2 → migrate`；其他抛错。导出仍写 v3。

**P1-6 空间计算器 `core/space.ts`**
- 输入：`design, assembly, cabinets[]`。
- 计算：
  1. `modulesPower = Σ ceil(width/slotWidth)`（zone=power 节点）、`modulesControl` 同理；`unknownWidth` 计数。
  2. `spare = design.spareRatio`；`rowsPower = ceil(modulesPower*(1+spare)/slots)`，`rowsControl = modulesControl>0 ? ceil(modulesControl*(1+spare)/slots) : 0`；`rowsNeeded = rowsPower + rowsControl`。
  3. `maxHeight = max(node.product.height)`，`maxDepth = max(node.product.depth)`。
  4. `heatW = Σ heatW`（未知按 0 并计 `heatUnknown`）。
  5. 对每个箱体：`fits = rows ≥ rowsNeeded && slots ≥ 每排需求 && rowClearance ≥ maxHeight && maxDeviceDepth ≥ maxDepth`；`excess = rows*slots - Σmodules`；排序：fits 优先、excess 小优先、非 estimated 优先。
  6. 生成“最小推荐规格”文字：`需要 {rowsNeeded} 排 × {slots}P（含 {spare*100}% 备用），器件最大高 {maxHeight} mm / 深 {maxDepth} mm，建议内部空间 ≥ W×H×D（估算）`。
- UI：左侧“项目配置”下新增“空间与箱体”折叠面板：模位统计（强电/弱电/备用）、推荐箱体列表（点击切换）、排分区开关、备用比例滑杆；右上 `#capacity` 沿用。
- 审计新增：`SPACE_ROWS`（当前箱体排数不足）、`SPACE_HEIGHT`、`SPACE_DEPTH`、`PRODUCT_WIDTH_UNKNOWN`、`HEAT_BUDGET`（pending，箱内估算功耗 > 箱体 `outer` 面积×0.005 W/cm² 的粗略阈值，文案注明“粗估”）。
- 测试：`tests/core/space.test.ts` 用默认方案：`modulesPower=108, rowsNeeded(spare .25)=ceil(135/24)=6`；加入 1 个 8 M 控制模块后 `rowsControl=1`。

- 三段：安装前（箱体/分区/预留/SELV 隔离）、接线中（N/PE 分排、每回路独立孔位、压接扭矩按产品 `torque`、线径按 `section`、总线极性/终端）、送电前（绝缘、RCD 试验按钮、相序、接地电阻、总线电压）。
- 数据：`design.checklist: Record<itemId,{checked,value,at,by}>`；文档页可打印空表或已填表。
- 验收：勾选保存后刷新仍在；打印页显示勾选状态。

**P3-3 修订与签认**
- 每次 `commit` 不写 revision；导出/打印时弹“记录修订摘要”并追加 `revisions`；`signoff` 三栏可填名字与日期；封面、系统图图题栏、铭牌显示 `Rev n` 与签认状态。
- 验收：导出两次得到 Rev 1/Rev 2。

**P3-4 ZIP 交底包**
- `fflate` 打包：独立 HTML、方案 JSON、系统图 SVG（各页）、标签 PNG、接线 CSV、回路 CSV、BOM CSV、校核 JSON、3D PNG、`README.txt`（口径声明）。
- 验收：ZIP 可解压，文件齐全。

- 记录：`docs/…-P3-施工包完成.md`。
