### 2.3 核心算法链（每次状态变更后 `ra()` → `gX()` 全量重算）

1. `eX()`：由 117 条源表按规则 `IU()` 聚合成回路（冰箱、弱电、影音、暖通、照明分区、厨房、插座分区），自动 `N1()` 三相平衡。
2. `kA(design, circuit)`：选型 —— 遍历截面 `bA=[1.5…35]`，按 `fr()`（Cu/PVC 载流量表 `Vo` × 温度系数 `Yr` × 成束系数 `_r`）算 Iz，找最小满足 `Ib ≤ In ≤ Iz`、端子范围、压降（照明 3% / 其他 5%）的 RCBO/MCB。
3. `Ka(design)`：装配 —— 生成节点 `Q0 / QSPD / SPD / Cxx / Cxx-RCD`，按 `HA` 顺序贪心填 `rows×24` 模位，支持 `position` 手动定位，溢出标 `overflow`。
4. `$s(design, assembly)`：配线网 —— 生成端子 `ports`（`节点:键`，如 `C01:L1_IN`）、导线 `wires`（`from>to`，含 `section/autoSection/protect/scope/downstreamProtection`）、内部通路 `internal`；含 `SERVICE / BUS / N排 / PE排 / CASE / DOOR / X-Cxx 出箱端子`。
5. `aX()`：供电可达性仿真（BFS），支持“模拟送电”“模拟跳闸”。
6. `AX()` + `sX()`：审计 —— 约 30 个规则码（`MAIN_OVERLOAD, RCD_MISSING, CABLE_MATCH, PLACEMENT, TERMINAL_RANGE, SOCKET_RATING, N_PE_BOND, SHARED_HOLE, PE_CONTINUITY, WIRE_IZ …`），分 `error / pending`。
7. `nX()`：**端子接线折叠图**（SVG，按“市电→总开→分配→本回路器件→出箱端子”阶段列布局），不是配电系统图。
8. `Qo`：three.js 3D —— 器件为程序化几何（RoundedBox + Canvas 贴花文字 + 螺钉 + LED），非 glTF；支持拆解、单件检视、缩略图缓存、截图。新增 `kind` 只需补贴花文案/颜色即可渲染。

## 3. 规划总览

### 3.1 总体原则

1. **先恢复可维护工程，再加功能**：不在 5.9 MB 压缩单文件上直接改。
2. **保留现有架构与交付形态**：继续纯前端、离线、单 HTML 可导出、localStorage 私有化；three.js/lucide 不换。
3. **数据 schema 升级到 v3 并提供 v2 → v3 迁移**：现有方案 JSON / 内嵌 HTML 必须可导入。
4. **每个新 kind 都要同时打通**：产品库校验 `Co` → 装配 `Ka` → 配线 `$s` → 审计 `AX/sX` → 3D 贴花 → 系统图/标签/BOM。
5. 不自动扩展到 HA 联动、云端等未提出的功能；只在“可选”里列出。

## 5. P1 智能模块产品

### 5.1 产品 kind 扩展（schema v3）

|---|---|---|---|
| `relay` | 导轨智能继电器/开关模块 | `channels, channelAmps, protocol(wifi/zigbee/knx/rs485/dry), powerInput(L+N / DC), meter(bool), heatW` | 串联在保护器之后、出箱端子之前（可多回路共用多通道） |
| `contactor` | 接触器 | `poles, ampsAC1/AC3, coilVoltage(220AC/24DC), aux` | 串联 |
| `dimmer` | 导轨调光模块 | `channels, channelW, output(TRIAC/0-10V/DALI), protocol` | 串联（仅照明回路） |
| `meter` | 电能表 | `phases, direct/ct, maxAmps, ctRatio, protocol(rs485-modbus/pulse/wireless), heatW` | 串联（直接式）或并联（CT 式，仅取电压） |
| `isolator` | 隔离开关 | `poles, amps` | 串联（进线侧 / 光伏侧） |
| `changeover` | 双电源切换 / ATS | `poles, amps, mode(manual/auto)` | 进线侧 |

| `timer` | 时控/光控继电器 | `channels, channelAmps` | 串联 |

### 5.2 回路模型：由“单保护器”改为“器件链”

```
circuit.devices = [
  { role:"protection", productId },          // MCB/RCBO（必需，保持 kA 自动选型）
  { role:"rcd", productId },                 // RCCB（可选，兼容 v2 rcdProductId）
  { role:"control", productId, channel:1 },  // relay/contactor/dimmer/timer（可选，可引用共享实例）
  { role:"meter", productId }                // meter（可选）
]
design.shared = [ { id:"K1", productId, kind:"relay", channelsUsed:{1:"C01",2:"C02"} } ]  // 多通道模块跨回路共享
design.dcBus = { psuId, consumers:[gatewayIds…] }
```

迁移：v2 `productId/rcdProductId` → v3 `devices[0..1]`；导出时保留 v3，导入 v2 自动迁移。

### 5.3 装配 `Ka` 扩展

- 引入**排级分区**：`power` 排（保护器）与 `control` 排（继电器/电源/网关），默认最下一排为 control 排，可手动改；
- 共享模块只占一处模位；
- 溢出/分区违规产生 `PLACEMENT_ZONE` 审计项；
- 3D：按 kind 提供贴花文案（如 "RELAY 4CH"、"kWh"、"24V DC"），颜色沿用 `color` 字段。

### 5.4 配线 `$s` 扩展

- 端子由产品 `ports` 模板生成（含 `AUX/A1/A2`、`RS485 A/B`、`DC+/DC-`、`S1/S2`）；
- 新增导线类：`class: "power"|"control"|"comms"|"dc"`，颜色与图例分开；
- 器件链按顺序串接：`protection → rcd → control → meter → X-出箱端子`；CT 式电表只接电压采样；
- 继电器/网关取电线从本回路或专用“智控电源回路”（建议自动建议一条 `C-SMART` 回路，由用户确认）。

### 5.5 审计规则新增（示例）

`RELAY_RATING`（通道额定 < 回路 In 或 < Ib）、`RELAY_NEEDS_N`（模块需 N 但回路无 N）、`DC_BUDGET`（电源输出 < 所有 DC 消费者之和×1.25）、`ZONE_MIX`（强弱电同排/相邻无隔离）、`HEAT_BUDGET`（箱内估算功耗超阈值，配合现有 `SPACE` 15% 规则）、`COMMS_TERMINATION`（RS485 未闭环/终端电阻待核）、`RCD_ELECTRONICS`（大量电子模块的漏电流叠加提示，pending）、`CT_DIRECTION`（CT 方向/变比待核）。所有涉及厂家参数的项保持 `pending`，不给“合格”结论，与现有口径一致。

## 6. P2 配电系统图

### 6.1 形式

按国内住宅常见“表格式系统图”：左侧进线区（进线电缆、总开关 Q0、SPD、计量/隔离），中间竖向母排，右侧每回路一列，列内自上而下：断路器符号（型号/极数/In/漏保 mA）→ 智控器件符号（KM/继电器/Wh）→ 电缆规格（`3×2.5 mm² Cu/PVC`、敷设 B2）→ 回路编号 / 用途 / Pe kW / Ib A / 相位。图题栏含方案名、日期、版本、"未签认"水印。

### 6.2 实现

- 纯 SVG 生成器 `renderSystemDiagram(design, assembly, matches)`，符号集自绘（GB/T 4728 基本符号：断路器、RCD、接触器、电表、隔离开关、SPD、端子）。参考 QElectroTech/KiCad 符号形态但**不复制其素材**（前者 GPL/CC-BY-SA，后者 CC-BY-SA），避免 License 传染。
- 导出：SVG（原生）、PDF（`jspdf` + `svg2pdf.js`，均 MIT；兄弟项目 `cabinet-design` 已用 jspdf）、DXF（`@tarikjabiri/dxf` 或 `dxf-writer`，均 MIT；复杂场景可用本机 `cad-editor` 技能的 ezdxf 后处理）。
- 与现有“端子接线”页签并列，新增“系统图”页签；点击列高亮对应回路（复用 `VA()` 选择逻辑）。

## 7. P3 自动标签

### 7.1 编号规则引擎

- 回路：`{id}` 默认 `C01`；可选模板 `{group}-{seq}`（如 `L-01` 照明）；名称/电流/相位/漏保作为标签第二行。
- 器件：`Q0 / QSPD / SPD / Cxx / Cxx-RCD / K1(继电器) / Wh1(电表) / G1(网关) / PS1(电源)`。
- 端子：将现有 `节点:键` 映射为施工编号 `X1:1…`（N 排、PE 排、出箱端子排各自连续编号），并写回 `wires`（`fromTag/toTag`），接线 CSV 同步输出。
- 导线：`{circuit}-{conductor}`（如 `C01-L1`）两端一致，号码管文本。

### 7.2 标签模板与输出

- 模板：断路器面标（18 mm 模位宽，单/双模）、箱门回路总表卡、号码管、端子排条、外部电缆挂牌、箱体铭牌（方案名/版本/二维码）。
- 排版输出：A4 标签纸 PDF（常见规格如 Avery/艾利 30 格、48 格可配置）、每枚 PNG、打印机导入 CSV（Brother P-touch Editor 数据库、精臣/硕方 App 导入）。
- 二维码：`qrcode`（MIT），内容为回路摘要或导出 JSON 的 URL/本地文件名；不含个人信息。
- 直连打印机为可选后续（Web Bluetooth + `niimbluelib`，MIT），本阶段不做。

## 8. P4 施工包

1. **附件 BOM**：在现有断路器清单基础上补箱体、导轨、N/PE 排、端子/分线器（按回路数与截面）、号码管、扎带、盖板 `blank`、智能器件、DC 电源；含参考价字段（沿用 `priceReference`，可与 `smart-home-quotation` 项目数据格式对齐，仅导出 CSV，不做报价系统）。
2. **线材估算**：箱内按 `wires` 逐段长度（由 3D 节点坐标 + 余量系数）汇总各截面/颜色米数；出箱电缆按回路 `length` × 芯数。
3. **箱门回路表**：打印版 A5/A4 卡片（回路号、名称、开关规格、相位、房间）。
4. **施工检查与验收单**：安装前（箱体/分区/预留）、接线中（N/PE 分排、压接扭矩按产品 `torque`、线径）、送电前（绝缘、RCD 测试按钮、相序、接地电阻），逐项勾选并记录数值、日期、签名（本地保存到方案 JSON）。
5. **修订与签认**：`design.revisions[]`（时间、摘要、审计错误数）、`signoff{designer,reviewer,installer}`；导出物统一带“未签认/已签认”状态与版本号。
6. **一键交底包**：ZIP（`fflate`，MIT）内含：独立 HTML、JSON、系统图 PDF/DXF、标签 PDF、接线 CSV、BOM CSV、检查单 PDF、3D PNG。
