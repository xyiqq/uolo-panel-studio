## 已亲自核实的重点问题

1. **高·电气安全**：`src/core/domain.js` `feedSection` 找不到满足载流的截面时回退 `35`。实测 80A 三相：环境 45°C → 35mm² Iz=78.2A；50°C → 70.3A；40°C 且 2 根并敷 → 68.9A；3 根并敷 → 60.3A，均低于 80A。`validateDesign` 通过，`auditDesign` 只给 `pending` 级 `SUPPLY_CAPACITY` 提示且文案写“35mm² 按录入敷设条件初筛”，无错误级告警。
2. **高·XSS**：`src/ui/app.js:328` 自定义分区 `${Ut(e.icon)}${e.name}` 未转义；`validateCustomGroup` 只限名称≤20 字符（`<svg/onload=alert()>` 恰为 20 字符），`icon` 不限内容。导入恶意 JSON 即可执行脚本。
3. **中高·XSS**：`app.js:401`、`app.js:445` `powerCell` 未转义；`app.js:93` `style="--tone:${a.color}"` 颜色未校验。
4. **高·可维护性**：`src/ui/app.js` 1025 行 / 140KB，最长一行 7577 字符，是 V4 压缩产物，新功能以可读代码插入其中，且仍在持续修改。
5. **中·死代码/存储**：`src/storage/local.js` 多方案适配器没有任何调用方；实际存盘为 `app.js` 把整份方案写入单个 `panel-studio-v4` 键，无多标签冲突检测。
6. **中·性能**：`src/view/terminal-studio3d.js:148` `poseKey` 含 `poseAmount`，爆炸动画期间每帧清空并重建全部端子线 TubeGeometry/SphereGeometry。
7. **低（原报告为高，已降级）**：100/125A 总开无内置 SKU。实测 `validateDesign` 会先拒绝（“当前电流没有对应内置主开型号”），UI 选项只到 80A，只有绕过校验直接调用 `buildAssembly` 时才抛错。
