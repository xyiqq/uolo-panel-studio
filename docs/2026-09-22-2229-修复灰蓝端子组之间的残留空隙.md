# 修复灰蓝端子组之间的残留空隙

- 时间：2026-09-22 22:29（Asia/Shanghai）
- 项目：uolo-panel-studio
- 需求：灰色端子组与蓝色端子必须紧邻，不能留下安装模位造成的空隙。

## 原因及修改
上次修复释放了真实空位，但新放入端子仍可能停在整数模位锚点，未追随前一组端子的实际右边界。本次在装配完成后，按每排实际位置将连续端子组紧贴，更新真实占位；中间有其他器件或跨排时不跨越。保留原保存锚点和编号，刷新时重复计算保持一致。

关键文件：src/core/modules.js、tests/core/module-placement.test.js。旧测试中“端子保留空模位间隔”的预期按本次明确要求改为紧贴；补充首排新增端子组之间边界相等的断言。
