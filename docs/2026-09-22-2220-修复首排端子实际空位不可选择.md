# 修复首排端子实际空位不可选择

- 时间：2026-09-22 22:20（Asia/Shanghai）
- 项目：uolo-panel-studio

## 用户需求与诊断
用户截图显示首排端子贴紧后右侧仍有空间，但下一组端子无法选择第一排。复现确认：3D 按实际宽度贴合，逻辑占位却逐组向上取整到18mm模位。十组交替8路灰端子与单路蓝端子实际宽234mm，但逻辑预留360mm，产生126mm不可用的虚假占位。拖拽另用旧slot比较，也存在同类问题。

## 实际修改
- 保留方案整数row/slot，装配时建立实际毫米占用区间，用于统一可用位置、碰撞检查、自动排布和手动固定。
- 保留旧相邻器件组的贴合关系；即使模块数组顺序改变，或新器件使用旧组释放的逻辑槽位，也不会打断既有贴合组。
- buildAssembly输出统一压紧后的布局，导出与页面采用相同几何位置。
- 拖拽移动改为使用和位置列表一致的canPlaceFootprint判断。
- 保留分区限制、真实碰撞和PDU跨排边界。

## 关键文件
src/core/placement-footprint.js、src/core/modules.js、src/core/domain.js、src/ui/app.js；tests/core/module-placement.test.js、tests/core/terminals-nbar.test.js。
