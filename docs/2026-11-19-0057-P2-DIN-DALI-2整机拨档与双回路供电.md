# P2 · DIN-DALI-2 整机拨档与双回路供电

uolo-panel-studio，记录于 2026-11-19 00:57。

## 需求和接线

整机保存 DALI POWER 的 INT／EXT 状态，按拨档计算 Cresnet 功耗，并为 DALI 1、DALI 2 单独配置外部电源。旧方案缺少拨档字段时沿用原有 INT 行为。DIN-DLI 继续只用内置 DALI 电源。

| 拨档 | Cresnet 24V 控制预算 | DALI 1 与 DALI 2 |
| --- | --- | --- |
| INT | 整机 9 W | 两路均由机内供电。编辑时切回 INT 并保存会解除两路外源分配 |
| EXT | 整机 2 W | 当前支持每路选一台有明确额定的单输出 DALI 电源。未选电源的回路显示待核，其他有效回路可出线 |

控制器 NET 24/G 或 LAN PoE 供电独立于 DALI 总线。每路 DALI 有两组同极并联端子，使用第一组 DA+/DA− 接收外源。重复使用同一组输出、误选普通 24V 电源、通用总线冲突或导入端子不完整均受校验。实际线径留给方案核实。

## 主要修改

- `src/data/products/smart-crestron.js` 记录按拨档区分的整机功耗。`src/core/dali-power.js`、`modules.js`、`bus-budget.js` 和 `module-wiring.js` 处理保存、预算、冲突和逐路接线。`ports.js` 定义网关的双 NET 和两路 DALI，以及 Lunatone 24033444 的上侧 DA+/DA−、下侧 N/L。
- `src/ui/dali-power-settings.js`、`src/ui/app.js` 和 `src/view/dali-power.js` 连接模块编辑、接线页和导出说明。三维端子、拨档和分开的芯线走向位于 `src/view/smart-device3d.js`、`studio3d.js`、`wire-routing.js`。接线表和 CSV 沿用同一组接线数据，默认线号保留 `DC-` 的负号。
- `tests/core/dali-power.test.js`、`tests/ui/dali-power-settings.test.js` 和 `scripts/check-din-dali-2.mjs` 提供回归。开发计划、交接文档、目录来源说明已更新。
