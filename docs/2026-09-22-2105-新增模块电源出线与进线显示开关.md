# 新增通信模块、电源出线选择与进线示意开关

- 时间：2026-09-22 21:05（Asia/Shanghai）
- 项目：uolo-panel-studio

## 用户需求
新增 USMART 两款 DIN-TCP（1 网口 + 2/4 个 RS-485 口）、明纬 HDR-100-12N / HDR-100-24N，并补齐 DLP-04R；电源除了上端空开，还需要选择下端连接的模块。图中的进线电源示意块需要显示/隐藏开关，导出同步。

## 实际修改
- USMART 两款采用用户指定的 HDR-100-24N 外形：70×90×54.5 mm、4M，绘制 LAN 与 2/4 个 RS-485 接口示意。未编造尚未提供的供电电压和额定参数。
- 新增两款完整 HDR 型号，保留旧通用 HDR-100 以兼容方案。12N 输出 12V/7.5A/90W，24N 输出 24V/4.2A/100.8W。
- DLP-04R 目录原已存在，本次补齐 16V/240mA/3.84W DALI 输出与资料来源，未重复添加。
- 电源编辑窗口加入“下端出线连接的模块”多选，写入现有 buses 模型，接线图、接线数据和交付使用同一关系。支持取消连接、保存重开和刷新恢复；修复编辑接收模块导致电源关联丢失。
- DC 接线严格匹配 12V/24V；DALI 按协议匹配。多电源接到同一接收端时标记待核，不自动并联。USMART 参数未知可保存关联，但不自动画供电线。
- 项目设置 → 界面与设计条件加入“显示进线电源示意”，默认显示。取消后隐藏进线块、标题及关联示意线；PNG 与 PDF 三维图跟随设置，实际电气接线数据不删除。
