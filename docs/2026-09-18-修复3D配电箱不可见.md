2026-09-18

## 目标与用户授权范围
用户反馈网页打开看不到配电箱。在既有 V5 实现范围内修复 Studio3D 机柜模型构建与可见性，不扩展新功能。

## 环境
- Windows / PowerShell
- Vite preview：`http://127.0.0.1:4175/`
- three.js r170；Playwright headless + ANGLE WebGL

## 操作与证据
1. Playwright 探测：`hasModel: false`，`pageerror: vA is not defined`（构建在 `uX` 门板材质处中断）。
2. 对照 V4：`side:vA` 为 Three 材质面常量；`Be` 已映射为 `DoubleSide`，故补 `vA = FrontSide`。
3. 同步补回 `yo`（按回路高亮导线 ID 集合），避免模型建成后 `updateVisibility` 再抛错。
4. `npm run build` 后重启 preview；`probe-scene.mjs`：`hasModel: true`，meshCount 1089，frame/rails/devices/wires 可见。
5. `probe-webgl.mjs` 截图 `docs/_smoke-3d-cabinet.png` 可见玛德克 MH-144 机柜；`npm test` 22 通过。

## 实际改动文件
