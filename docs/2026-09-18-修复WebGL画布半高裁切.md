# 2026-09-18 修复 WebGL 画布半高裁切

## 日期
2026-09-18

## 目标与用户授权范围
用户澄清：下半柜被“整块画布”挡住，不是工具图标遮挡。排查并修复 3D 宿主高度异常。

## 环境
- Playwright 探测 `http://127.0.0.1:4175/`

## 操作与证据
1. 探测：`.canvas-wrap` 高 758px，但 `#canvas` / WebGL 仅 432px；`#canvas` 内联 `position: relative`（CSS 本应为 absolute）。
2. 根因：`src/ui/v5-bridge.js` 为挂文档中心面板执行了 `canvas.style.position = "relative"`，导致 WebGL 宿主按内容半高排布，下半截只露容器底色，看起来像整块画布挡住机柜。
3. 修复：文档面板改挂到 `.canvas-wrap`；清除 `#canvas` 上被写入的 `position`/`visibility`。
4. 复测：host/canvas 均为 864×758；截图整柜可见，无水平切断。

## 实际改动文件
- `src/ui/v5-bridge.js`
- 本记录；验证截图沿用 `docs/_smoke-3d-cabinet.png`

## 验证结果
- `position: absolute`，缓冲高度与 wrap 一致
- 机柜上下完整可见

## 风险与未验证项
- 文档中心面板需再点开确认仍覆盖装配区
- 用户需硬刷新

## 回滚方式
还原 `v5-bridge.js` 本轮改动并重建。
