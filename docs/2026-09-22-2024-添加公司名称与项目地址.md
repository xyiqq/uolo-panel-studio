# 添加公司名称与项目地址

用户要求增加公司名称、项目地址，并确定填写位置。

- 填写入口：左侧项目配置 → 项目信息与设计条件 → 项目基本信息。原设置入口名称更新，方便找到。
- 新增公司名称（120 字）和项目地址（240 字、多行）选填项，按当前方案保存。简易和完整模式均支持填写与清空。
- PDF 首页项目名称下显示公司与地址；地址保留换行，占满一整行，继续保留箱体尺寸。
- 关键文件：`src/ui/app.js`、`src/styles/app.css`、`src/view/documents/cover.js`、`src/styles/documents.css`。
- 验证：实际浏览器覆盖简易与完整模式保存、刷新回填、PDF 首页显示；构建通过。导出样张为一页 A4 竖向，渲染检查无重叠或截断。方案校验保留新增字段。
- 样张：`output/pdf/项目基本信息-封面样张.pdf`。示例公司与地址仅用于隔离浏览器验收，未替用户填写真实项目资料。未提交或部署。
