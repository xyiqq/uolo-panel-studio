# 修复交换机多行备注字号

- 用户需求：修复交换机网口备注换为两行时字号不一致的问题。
- 原因：每行根据自己的字符数量独立计算字号，较短的第二行被放大。
- 修改：同一网口备注根据最长行估算宽度统一字号，保留完整文本、居中和原有换行；SVG和三维Canvas贴图共用修正后的图元。
- 关键文件：src/view/module-face.js、tests/view/network-switch-geometry.test.js。
- 验证：相关14项测试通过，覆盖IP地址、中英文混排、三行备注与模型面板边界；npm run build成功。Chrome实际Canvas渲染检查两行IP字号均为15.48549，文字完整无越界。
- 视觉证据：docs/_smoke-switch-multiline-font.png。
- 范围：仅修复网口备注排版，保留现有其他未提交改动，未提交或推送。
