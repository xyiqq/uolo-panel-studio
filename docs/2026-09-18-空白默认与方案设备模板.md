# 2026-09-18 · 空白默认、空开模板与自定义箱体 P 长度显示

## 日期
2026-09-18

## 目标与用户授权范围
用户要求：
1. 自定义箱体「每排 P 数」旁显示对应长度（mm），便于对照实际尺寸。
2. 新建方案不再内置默认支路空开。
3. 内置若干「按空开数量」起步模板。
4. 支持把当前设备组合保存成模板，下次一键调用。

授权：在现有配电工坊前端实现上述能力；保留 `createDefaultDesign` 供黄金测试与「全屋演示」模板。

## 环境
- 项目：`uolo-配电箱`（panel-studio v5）
- Node + Vite 本地构建；Vitest 单元测试

## 操作与证据
1. 新增 `src/data/design-templates.js`：空白方案、空开包工厂、内置模板列表、用户模板 localStorage、P 长度提示。
2. 修改 `src/ui/app.js`：默认 `createBlankDesign()`；自定义箱体对话框增加 `slotsLengthHint`；侧栏「方案模板 / 存为设备模板」；画布尺寸文案改为真实 `slots`P 与 `slots×18` mm；拖放上架使用 `kt.box.slots`。
3. 新增 `tests/core/design-templates.test.js`；保留 `tests/golden/v4-default.test.js` 对全屋演示的覆盖。

## 风险与未验证项
- 若本机仍有旧 `localStorage`（`panel-studio-v4`）存的全屋方案，刷新会继续加载旧方案，不会自动变空白；清空站点数据或点「方案模板 → 空白箱体」即可。
- 用户模板键：`panel-studio-v5:design-templates`，最多约 40 条，未做跨设备同步。
- 内置空开模板固定为施耐德 `A9D32616`（iDPN N Vigi C16），非工程选型结论。
- 拖放上架的 `>kt.box.slots` 修复未单独做 UI 回归。
