# 2026-09-18 修复 DIN-DALI-2 无法上架三维

## 日期
2026-09-18

## 目标与用户授权范围
用户反馈装入 Crestron DIN-DALI-2 后配电箱三维中看不到。定位并修复；仅填入已核验厂家外形，不编造电气额定。

## 环境
- 本地 Vitest / Vite build
- Crestron 官方产品页 / Spec Sheet（DIN-DALI-2 等 9M/6M/12M 占位）

## 操作与证据
1. `makeSmartProduct` 默认 `width/modules=null`；`buildAssembly` 在 `modules==null` 时 `for (d=0;d<null)` 不占位，三维 `cube` 把 null 收成 0.5mm，几乎看不见。
2. 复现：装入后节点 `modules:null,width:null,row:0,slot:0,x:-216`。
3. 填入 DIN-DALI-2 官方 **9M / 162mm**，高 95、深 60；同步核验其余 Crestron DIN 占位（AP4/8SW8-I/1DIMU4/4DIMFLV4/2MC2/PWS50）。`DIN-4DIMU4` 仍待本型号资料。
4. 加固排位：无模位 → `overflow` + `placementError`；装入提示区分「无尺寸暂不上架」。
5. 复测：`C99` → `modules:9,width:162,row:3,slot:0`，非 overflow。测试 22 通过。
