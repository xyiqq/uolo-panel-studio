## 操作与证据
1. 根因：`domain.js` 的 `CABINETS` 仅 MH144/Q120/Q96；`Y1` 每次用 `Za` 重写下拉，冲掉 v5-bridge 追加的通用选项；选 `GEN-*` 时 `validateDesign`/`buildAssembly` 失败。
2. 增加 `resolveCabinet` / `validateCustomCabinet`，`buildAssembly`/`validateDesign` 认玛德克 + `GENERIC_CABINETS` + `design.customCabinets`。
3. `fillCabinetSelect` 按 optgroup（玛德克 / 通用估算 / 自定义）填充；「自定义箱体…」走 `makeGenericCabinet` 写入 `USR-CAB-*`。
4. 移除 v5-bridge 的 `extendCabinetSelect` 追补，避免与 Y1 打架。
