# 空开链路拆解与线号线径批量填写

## 需求与修改
- 拆解范围选择框改为与深色工具栏一致的背景、边框、字号、高度和箭头，文字调整为“所选器件拆解”。
- 选择分支空开时，将所带模块、独立漏保（如有）及模块端子按链路分层拆解，显示下游馈线和所有端子线详情，不沿共用 N/PE 扩散到其他分支。
- 单支路视图排除上游柜内长线；远处零线排用就近“零线排引入”参考点表示。仅改变检视表现，不修改电气连接数据。说明置于下游模块旁。
- 新端子线径默认 1.5 mm²，已有明确配置保留。修改本组第一节线径后提示是否统一本组其他端子，明确提示覆盖已有线径。
- 首节线号使用末尾数字递增规则，保留前缀和补零位数：例如 L01→L02，WL-009→WL-010。提示后批量填写本组空白线号，保留已有线号并跳过已使用编号；没有数字后缀时提示输入规则。
- 批量操作只改草稿，点击“保存接线”才持久化。
