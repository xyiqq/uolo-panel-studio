# 空开与模块一对一馈电显示

时间：2026-09-21 22:27（Asia/Shanghai）。

## 用户需求

总空开作为首个上游空开，其余空开与模块一对一；补空开到模块火线并显示零线和新增连接。

## 实际修改

- `src/core/module-feeds.js`：简易模式按安装排/槽顺序将支路空开一对一对应模块。显式关联优先，总空开Q0、端子、纯低压网关和380V支路不参与默认分配；完整模式仅处理显式绑定。
- `src/core/domain.js`：将馈线接入正式net.wires，支持接线清单、三维、导线断开与线径覆盖保存。复用原支路导线的相别、截面与保护信息。
- DIN-8SW8-I只生成负载侧火线，保留其支路原有N路径，不虚构模块N输入；需要N的LN模块从同一支路/RCD取N，1P空开无N输出时沿用原N排路径。
- 将被替换的X相线端保留为逻辑供电状态参考，不增加可见实体导线；断开模块馈线时原回路供电状态跟随失电。
- `src/ui/app.js`：默认全部连线，模块下拉改为对应支路空开（一对一），总空开和已用支路不再列为可分配项；通道清单显示推导的对应空开。
